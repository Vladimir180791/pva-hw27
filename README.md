# Log Parser

Скрипт для анализа access.log файлов веб-сервера.

## Возможности

- Подсчет общего количества запросов
- Статистика по HTTP-методам (GET, POST, PUT, DELETE, etc.)
- Топ 3 IP-адресов по количеству запросов
- Топ 3 самых долгих запросов с детальной информацией
- Поддержка обработки отдельных файлов и директорий
- Сохранение результатов в JSON формате
- Вывод статистики в терминал

## Установка

```bash
git clone <repository-url>
cd log-parser
